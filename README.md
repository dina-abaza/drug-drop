# **Drag and Drop Project**

This project demonstrates a simple **Drag and Drop** functionality using **HTML**, **CSS**, and **JavaScript**. It allows users to drag elements from one location and drop them into another. This functionality can be useful for various interactive web applications such as organizing tasks, images, or files.

---

## **Features**:

- **Drag and Drop Functionality**: Users can drag elements and drop them in a new location on the page.
- **Interactive UI**: The project provides a simple, interactive interface for users to rearrange items.
- **JavaScript Implementation**: The project is built using vanilla **JavaScript** for drag and drop operations.
- **CSS Styling**: Basic styling to make the elements visually appealing and responsive.

---

## **How It Works**:

1. The user can click and drag an item (such as a box or image) from one area of the page.
2. Once the item is dragged over a valid drop target, the user can release the item, and it will be placed in the new location.
3. The `dragstart`, `dragover`, `drop`, and `dragend` events in **JavaScript** are used to handle the drag-and-drop functionality.
   
---

## **Technologies Used**:

- **HTML**: For creating the structure of the webpage and defining draggable items.
- **CSS**: For styling the page and creating visual effects (e.g., change of colors, borders when dragging).
- **JavaScript**: For implementing the drag and drop functionality, handling events, and manipulating DOM elements.
